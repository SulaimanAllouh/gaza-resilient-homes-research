# Which source governs these nine rows?

The supplied final thesis, V22, governs this release. All nine counts, valid denominators and one-decimal percentages also agreed with an archived aggregate output of the same study. An execution register corroborated the categories and denominators; that register does not store the numerator in a separate column. This triangulates reported outputs. It is not an independent study or a recalculation from original survey records.
