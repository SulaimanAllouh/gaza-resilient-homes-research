# Access, citation and reuse

## Citing a finding

The empirical source is the thesis, not the code. Cite the author, manuscript version, table or section, and printed page. The tables also give the one-based PDF page for readers using a PDF viewer.

> Allouh, S. M. S. (2026). *A Practical Framework for Building Resilient and Sustainable Homes in War-Affected Regions: A Gaza Case Study* [Master's thesis manuscript, The Islamic University–Gaza]. V22, October 2026, Table 4.7 and note, pp. 82–83.

The table and pages in that example refer to water-storage capacity. For a different finding, use the locator in its own aggregate row.

## Citing the companion

> Allouh, S. M. S. (2026). *Gaza Resilient Homes Research: selected household indicators* (Version 0.1.0) [Research software and aggregate tables].

[CITATION.cff](../CITATION.cff) identifies this software companion and separately references its thesis source. When referencing a public copy, include the URL of the version you actually used. No DOI has been assigned in this package.

For reuse of covered materials, follow the [license map](../LICENSE.md). An attribution for an adapted chart can identify Sulaiman M. S. Allouh, *Gaza Resilient Homes Research*, version 0.1.0, link to the source and CC BY 4.0, and say what changed (for example, “Arabic labels shortened for display”). Rights in the presentation or compilation of the material do not create exclusive rights in every underlying fact.

## Participant data and source materials

The companion includes nine selected aggregate facts, release-specific labels and denominator notes, new code and a separate, invented teaching example. It does not distribute the thesis PDF, full instruments, historical analysis scripts, operational software, participant records, linkage keys or interview materials. No access to individual records is promised. V22 records consent confirmation for the household interviews, not permission for unrestricted release of participant records (printed pp. 68–69; Appendix A, pp. 120–121).
